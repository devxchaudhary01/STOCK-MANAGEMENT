# Admin guide (plain language)

**Daily:** open **Dashboard**. Red = order now, dark red = none left, yellow = getting low. Click a card or a supplier name to filter. **Export Excel** downloads exactly what you see.

**What to order from whom:** **Reorder** (or Suppliers → click a name) → list for that supplier with *Order qty* → **Export Excel** → send to supplier.

**Record a purchase:** Purchases → Add purchase → date, supplier, item, quantity, invoice number (photo/PDF optional) → Save. Stock goes up automatically. A wrong entry? Purchases → Cancel (stock is reversed and logged).
**Invoice with many lines:** Import / Export → Invoice → upload photo/PDF → check each line (green is matched, red needs an item chosen) → Confirm.

**Set or change criteria for any item:** Items → Edit. Enter *Target stock*, then choose either *percentage* (blank = default 50%) or a *direct level*. The screen shows which rule is in use. Priority and supplier are on the same screen.
**Give many items a supplier at once:** Items → filter (e.g. by category) → *Assign supplier to these items*.

**Stock count / correction:** Stock → Record a stock movement (Adjustment needs a reason). For many items use Import / Export → Bulk stock quantity (upload Item name + Quantity; check Matched / Unmatched / Duplicates / Invalid; Confirm).

**Change the 50% rule:** Settings → Stock rules (also: exact-boundary behaviour and the yellow band).
**Add a supplier / user:** Suppliers → Add supplier. Settings → Add user.
**Made a bad import?** Import / Export → Import history → Undo.
